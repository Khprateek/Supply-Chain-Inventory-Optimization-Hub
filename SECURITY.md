# Security Policy

## Supported Versions

We release security updates and patches for active versions of the Enterprise Open Data Lakehouse Platform:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The project team and contributors take the security of this platform seriously. If you discover a vulnerability or security risk, please do **NOT** disclose it publicly via GitHub Issues.

### Reporting Procedure:
1. Privately disclose the issue via email to the project maintainers or via GitHub's [Private Vulnerability Reporting](https://github.com).
2. Include in your report:
   * Description of the vulnerability and its potential impact.
   * Step-by-step reproduction instructions or proof-of-concept script.
   * Environment details (Docker version, PySpark version, operating system).
   * Any suggested remediations or patches.

### Our Commitment:
* We will acknowledge receipt of your report within **48 hours**.
* We will assess the issue and provide a confirmation along with an expected remediation timeline within **5 business days**.
* Once the vulnerability is patched, we will publicly credit you in the release notes (unless you prefer to remain anonymous).
